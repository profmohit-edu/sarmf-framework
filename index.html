SARMF-Bench

SARMF-Bench is a deterministic, reproducible smart contract vulnerability benchmark aligned with canonical SWC taxonomy classes:

  • SWC-107 – Reentrancy
  • SWC-101 – Integer Overflow
  • SWC-105 – Access Control Weakness
  • SWC-104 – Unchecked External Calls
  • SWC-113 – Denial-of-Service via Unbounded Loop
