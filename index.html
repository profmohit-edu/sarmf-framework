SARMF-Bench

SARMF-Bench is a distributed, DOI-backed benchmark infrastructure for systematic smart contract vulnerability evaluation and AI-driven blockchain security research.

Institutional Anchor

Cybersecurity & Blockchain Research Initiative

SARMF-Bench is developed and maintained under an independent cybersecurity research initiative at Bharati Vidyapeeth's College of Engineering, Delhi, focusing on secure smart contract engineering, AI-driven vulnerability assessment, and reproducible blockchain security benchmarking.

This initiative contributes to secure digital infrastructure research aligned with higher education cyber maturity frameworks and industry-grade blockchain security practices.

Infrastructure Architecture

  • Development Layer: Public GitHub repository with version-controlled source code.
  • Software Archival Layer: Zenodo DOI-backed artifact preservation.
  • Benchmark Dataset Layer: Harvard Dataverse structured archive.
  • Mirror Preservation Layer: Mendeley Data redundancy.
  • Open Science Layer: OSF project documentation.
  • Reproducibility Layer: protocols.io methodological archive.

Research Positioning

SARMF-Bench establishes a reproducible security engineering benchmark for Ethereum-compatible smart contracts, enabling structured vulnerability evaluation, mitigation analysis, adversarial testing, and AI-driven assessment workflows.
