SARMF-Bench

Distributed DOI-backed benchmark infrastructure for smart contract security research.

SARMF-Bench is a reproducible smart contract vulnerability benchmark framework designed to support AI-driven blockchain security research, mitigation evaluation, and adversarial testing.

Official Research Assets

  • Primary Development Repository (GitHub)
  • Software Snapshot (Zenodo)
  • Benchmark Dataset (Harvard Dataverse)
  • Dataset Mirror (Mendeley Data)
  • Open Project (OSF)
  • Reproducibility Protocol (protocols.io)
