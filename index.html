SARMF-Bench

Distributed, DOI-backed benchmark infrastructure for smart contract vulnerability evaluation and AI-driven blockchain security research.

Research Infrastructure Initiative — BVCOE Delhi

Infrastructure Architecture

  • Development Layer: Public GitHub repository with version-controlled source code.
  • Software Archival Layer: Zenodo DOI-backed snapshot ensuring artifact preservation.
  • Benchmark Dataset Layer: Harvard Dataverse structured dataset archive.
  • Mirror Preservation Layer: Mendeley Data archival redundancy.
  • Open Science Layer: OSF project documentation.
  • Reproducibility Layer: protocols.io methodological workflow archive.

Official Research Assets

  • Primary Development Repository (GitHub)
  • Software Snapshot (Zenodo)
  • Benchmark Dataset (Harvard Dataverse)
  • Dataset Mirror (Mendeley Data)
  • Open Science Project (OSF)
  • Reproducibility Protocol (protocols.io)

Research Positioning

SARMF-Bench establishes a reproducible security engineering benchmark for Ethereum-compatible smart contracts, enabling systematic vulnerability evaluation, mitigation analysis, adversarial testing, and AI-driven assessment workflows.
