# SARMF Smart Contract Security Engineering Lab (BVCOE Delhi)

A reproducible security engineering workflow for Ethereum-compatible smart contracts:
- Protocol DOI (methodology): https://dx.doi.org/10.17504/protocols.io.bp2l6eyxdgqe/v1
- Software DOI (artifact snapshot): https://doi.org/10.5281/zenodo.18754015

## What students will do (lab tracks)
1. Benchmark static analysis (Slither, Mythril) on real vulnerable contracts
2. Apply SARMF mitigation templates and measure security delta
3. Validate with adversarial tests + fuzzing
4. Report gas overhead vs security improvement
