# CNSRG – Cyber & Network Security Research Group
(BVCOE Delhi)

## Faculty-Led Research Vertical

SARMF (Smart Contract Automated Remediation and Mitigation Framework) is currently operating under CNSRG as a faculty-led research initiative focused on:

- Reproducible smart contract security engineering
- Vulnerability normalization aligned with SWC taxonomy
- Automated mitigation modeling
- Security delta benchmarking
- DOI-indexed research artifact preservation

## Current Operating Model

This phase emphasizes:

1. Infrastructure stabilization
2. Benchmark dataset construction
3. Empirical evaluation
4. Scopus/WoS-targeted publication

Student onboarding will resume after the stabilization phase.
